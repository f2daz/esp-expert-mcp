# ESP-IDF

Espressif's official framework (C, CMake, FreeRTOS). Never state versions from memory – use `framework_versions` or `idf_target_support` (which chip is supported from which IDF version).

## Project structure

```
project/
├── CMakeLists.txt            # top level, three mandatory lines
├── sdkconfig.defaults        # checked in: desired deviations from the defaults
├── sdkconfig.defaults.esp32s3 # optional, loaded additionally when target = esp32s3
├── sdkconfig                 # generated – do not maintain as source
├── partitions.csv            # optional, via CONFIG_PARTITION_TABLE_CUSTOM
├── dependencies.lock         # generated by the Component Manager
├── main/
│   ├── CMakeLists.txt
│   ├── idf_component.yml     # dependencies from the Component Registry
│   └── main.c                # void app_main(void)
├── components/<name>/        # project-specific components
│   ├── CMakeLists.txt
│   ├── include/<name>.h
│   └── <name>.c
└── managed_components/       # fetched by the Component Manager – do not edit
```

Top-level `CMakeLists.txt` (the order is mandatory):

```cmake
cmake_minimum_required(VERSION 3.22)
include($ENV{IDF_PATH}/tools/cmake/project.cmake)
project(my_project)
```

Component `CMakeLists.txt`:

```cmake
idf_component_register(SRCS "sensor.c"
                       INCLUDE_DIRS "include"
                       REQUIRES esp_driver_i2c      # public (needed in the header)
                       PRIV_REQUIRES esp_timer)     # internal only
```

- `REQUIRES` only what the public headers need; everything else `PRIV_REQUIRES`.
- From IDF 6.0, the umbrella component `driver` no longer pulls in the `esp_driver_*` components publicly – list drivers explicitly (e.g. `esp_driver_gpio`, `esp_driver_uart`, `esp_driver_i2c`).

### sdkconfig.defaults

- Enter only deviations, one option per line: `CONFIG_FREERTOS_HZ=1000`.
- `sdkconfig.defaults.<target>` is loaded **additionally**, but only if `sdkconfig.defaults` exists.
- Multiple files: `idf.py -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.prod" build`.
- Changes to the defaults have no effect while an old `sdkconfig` exists – delete `sdkconfig` or run `idf.py fullclean`/`set-target`.
- Generate defaults from a configuration worked out in menuconfig: `idf.py save-defconfig`.
- Check with `sdkconfig_analyze` / individual values with `sdkconfig_get`.

## idf.py – key commands

| Command | Purpose |
|---|---|
| `idf.py set-target esp32s3` | Set target; **deletes build and sdkconfig** |
| `idf.py menuconfig` | Interactive configuration (then `save-defconfig`) |
| `idf.py build` | Build |
| `idf.py -p /dev/cu.usbmodem1101 flash monitor` | Flash and monitor (get confirmation) |
| `idf.py -p PORT -b 921600 flash` | With a higher baud rate |
| `idf.py -p PORT app-flash` | App partition only |
| `idf.py monitor` | Serial monitor with address decoding |
| `idf.py size` / `size-components` / `size-files` | Memory usage total / per component / per file |
| `idf.py clean` / `fullclean` | Delete build output / entire build directory |
| `idf.py reconfigure` | Re-run CMake (e.g. after adding a component) |
| `idf.py save-defconfig` | Minimal `sdkconfig.defaults` from the current configuration |
| `idf.py create-project NAME` | New project |
| `idf.py create-component NAME` | New component (run in `components/`; check the target directory option) |
| `idf.py add-dependency "espressif/led_strip^3"` | Add dependency to `main/idf_component.yml` |
| `idf.py update-dependencies` | Re-resolve dependencies |
| `idf.py -p PORT erase-flash` | **Erase entire flash** incl. NVS – only after approval |
| `idf.py -p PORT coredump-info` | Read core dump from flash and analyze it |
| `idf.py -p PORT coredump-debug` | Open core dump in GDB |

- From IDF 6.0: `idf.py size --legacy` removed; `--format json` is now `--format json2`.
- From IDF 6.0: all `idf.py efuse*` commands require an explicit `--port`/`ESPPORT`. eFuse commands are irreversible.
- Default port via environment variable: `ESPPORT`, baud rate `ESPBAUD`.

## IDF Monitor – keys

| Key | Function |
|---|---|
| `Ctrl+]` | Exit monitor |
| `Ctrl+T` `Ctrl+R` | Reset target via RTS |
| `Ctrl+T` `Ctrl+F` | Build and flash project |
| `Ctrl+T` `Ctrl+A` | Build and flash app only |
| `Ctrl+T` `Ctrl+P` | Reset into bootloader (halt app) |
| `Ctrl+T` `Ctrl+Y` | Pause/resume log output |
| `Ctrl+T` `Ctrl+L` | Toggle logging to file |
| `Ctrl+T` `Ctrl+I` | Toggle timestamps |
| `Ctrl+T` `Ctrl+H` | Show all shortcuts |

- The monitor automatically decodes code addresses and backtraces against the project's ELF (can be disabled: `--disable-address-decoding`). Only meaningful with the **exactly matching ELF**; otherwise use `serial_log_analyze` with the ELF.

## Component Manager

`main/idf_component.yml`:

```yaml
dependencies:
  idf: ">=5.3"                      # IDF version constraint
  espressif/led_strip: "^3"         # registry, SemVer range
  espressif/mqtt: "*"               # no longer included in IDF from 6.0
  my_driver:
    git: https://github.com/org/repo.git
    path: components/my_driver
    version: v1.2.0                 # pin a tag/commit, not a branch
  local_lib:
    path: ../shared/local_lib
  espressif/button:
    override_path: ../patched_button
  esp_tinyusb:
    version: "^1"
    rules:
      - if: "target in [esp32s2, esp32s3, esp32p4]"
```

- Registry: https://components.espressif.com/
- Do not edit `managed_components/` and `dependencies.lock` by hand. Check in `dependencies.lock` if reproducible builds are wanted (project decision; the docs do not mandate it).
- After changes to the manifest: `idf.py reconfigure` or `build`.

## Installation

- **From IDF 6.0: ESP-IDF Installation Manager (EIM)**, GUI or CLI.
  macOS: `brew tap espressif/eim` → `brew install eim` (CLI) or `brew install --cask eim-gui`.
  `eim install` (latest stable), `eim install -i v5.5.x` (specific version), `eim wizard` (interactive).
  The environment is activated via activation scripts generated by EIM (verify path/name, `eim --help`).
- **Legacy (versions before 6.0):**
  ```bash
  git clone --recursive https://github.com/espressif/esp-idf.git
  cd esp-idf && ./install.sh esp32,esp32s3
  . ./export.sh          # in every new shell
  ```
- From IDF 6.0 minimum requirements: Python ≥ 3.10, CMake ≥ 3.22.1.
- Multiple IDF versions side by side are common – always check which `IDF_PATH` is active (`idf.py --version`).

## Migration ESP-IDF 5.x → 6.x

Official guide (read before every migration; there are also 6.0→6.1 and 6.1→6.2):
https://docs.espressif.com/projects/esp-idf/en/latest/esp32/migration-guides/

### Drivers (peripherals)

**Removed in 6.0** (legacy drivers), replacements:

| Old (removed) | New |
|---|---|
| `driver/adc.h` | `esp_adc/adc_oneshot.h`, `adc_continuous.h`, `adc_cali.h` |
| `driver/timer.h` (Timer Group) | `driver/gptimer.h` |
| `driver/i2s.h` | `driver/i2s_std.h`, `i2s_pdm.h`, `i2s_tdm.h` |
| `driver/mcpwm.h` | `driver/mcpwm_prelude.h` |
| `driver/pcnt.h` | `driver/pulse_cnt.h` |
| `driver/rmt.h` | `driver/rmt_tx.h`, `rmt_rx.h`, `rmt_encoder.h` |
| `driver/dac.h` | `driver/dac_oneshot.h`, `dac_continuous.h`, `dac_cosine.h` |
| `driver/sigmadelta.h` | `driver/sdm.h` |

- **I2C legacy (`driver/i2c.h`)**: **EOL** in 6.0, **removal planned for 7.0**. The warning can be suppressed temporarily with `CONFIG_I2C_SUPPRESS_DEPRECATE_WARN` – migrate to `driver/i2c_master.h` / `i2c_slave.h` anyway. The old and new I2C drivers must not be mixed.
- UART: `UART_FIFO_LEN` → `UART_HW_FIFO_LEN`. LEDC: `ledc_timer_set()` removed. GPIO: `gpio_uninstall_isr_service()` now returns `esp_err_t`.
- 6.1: `uart_set/get_wakeup_threshold()` deprecated → `uart_wakeup_setup()` (`driver/uart_wakeup.h`).

New I2C master API (available since IDF 5.2 – verify; for new code from 6.0 the only future-proof option):

```c
#include "driver/i2c_master.h"

i2c_master_bus_config_t bus_cfg = {
    .i2c_port = I2C_NUM_0,
    .sda_io_num = GPIO_NUM_8,
    .scl_io_num = GPIO_NUM_9,
    .clk_source = I2C_CLK_SRC_DEFAULT,
    .glitch_ignore_cnt = 7,
    .flags.enable_internal_pullup = true,   // does not replace external pull-ups
};
i2c_master_bus_handle_t bus;
ESP_ERROR_CHECK(i2c_new_master_bus(&bus_cfg, &bus));

i2c_device_config_t dev_cfg = {
    .dev_addr_length = I2C_ADDR_BIT_LEN_7,
    .device_address = 0x76,
    .scl_speed_hz = 400000,
};
i2c_master_dev_handle_t dev;
ESP_ERROR_CHECK(i2c_master_bus_add_device(bus, &dev_cfg, &dev));

uint8_t reg = 0xD0, id;
esp_err_t err = i2c_master_transmit_receive(dev, &reg, 1, &id, 1, 100 /* ms */);
```

ADC oneshot (instead of `adc1_get_raw`):

```c
#include "esp_adc/adc_oneshot.h"

adc_oneshot_unit_handle_t adc;
adc_oneshot_unit_init_cfg_t ucfg = { .unit_id = ADC_UNIT_1 };
ESP_ERROR_CHECK(adc_oneshot_new_unit(&ucfg, &adc));
adc_oneshot_chan_cfg_t ccfg = { .atten = ADC_ATTEN_DB_12, .bitwidth = ADC_BITWIDTH_DEFAULT };
ESP_ERROR_CHECK(adc_oneshot_config_channel(adc, ADC_CHANNEL_2, &ccfg));
int raw;
ESP_ERROR_CHECK(adc_oneshot_read(adc, ADC_CHANNEL_2, &raw));   // not from an ISR
```
Calibration to mV via `adc_cali_create_scheme_curve_fitting()` or `..._line_fitting()` – depending on the chip (`ADC_CALI_SCHEME_*_SUPPORTED`).

### System, toolchain, build

- **LibC: Newlib → Picolibc** as the default (from 6.0); `stdin/stdout/stderr` global, no longer per task. Newlib optional via `CONFIG_LIBC_NEWLIB`.
- **GCC 14.2 → 15.1** (6.0): new warnings; **default warnings are treated as errors**. Workaround `CONFIG_COMPILER_DISABLE_GCC15_WARNINGS` – better to fix the code.
- The linker aborts with an error on orphan sections. Global constructors now run in ascending order.
- Kconfig: esp-idf-kconfig v3 (adapt your own Kconfig files if necessary).
- **FreeRTOS** removed: `xTaskGetAffinity`, `xTaskGetIdleTaskHandleForCPU`, `xTaskGetCurrentTaskHandleForCPU`, `xQueueGenericReceive`, `vTaskDelayUntil` → `xTaskGetCoreID`, `xTaskGetIdleTaskHandleForCore`, `xQueueReceive`, `xTaskDelayUntil`. FreeRTOS code is placed in flash instead of IRAM by default (`CONFIG_FREERTOS_IN_IRAM` to revert). Same for the ring buffer (`CONFIG_RINGBUF_IN_IRAM`).
- Sleep: `esp_sleep_get_wakeup_causes()` replaces `esp_sleep_get_wakeup_cause()`; `esp_deep_sleep_enable_gpio_wakeup()` → `esp_sleep_enable_gpio_wakeup_on_hp_periph_powerdown()`.
- Core dump: ELF format only, SHA256 instead of CRC32.

### Networking and protocols

- **ESP-MQTT** removed from IDF → component `espressif/mqtt` (API `mqtt_client.h` unchanged).
- **`json`** (cJSON) removed → `espressif/cjson`.
- ESP-TLS: wolfSSL support removed; `esp_tls_conn_http_new()` → `..._sync()`/`..._async()`.
- HTTP server: the WebSocket URI handler is no longer called during the handshake (from 6.0.1) → `ws_post_handshake_cb`.
- LwIP: `sntp.h` → `esp_sntp.h`; old ping API removed → `ping/ping_sock.h`; the TCP/IP task is named `tcpip` instead of `tiT`.
- ESP-NETIF: `esp_netif_next()` removed → `esp_netif_find_if()` or similar. Ethernet PHY drivers moved out (`esp-eth-drivers`).

### Migration procedure

1. Go through the migration guides of all skipped minor versions.
2. `idf.py fullclean`, then build and work through errors/warnings one by one.
3. Add removed components back via `idf.py add-dependency`.
4. Check `sdkconfig.defaults` for renamed options (`sdkconfig_analyze`); the build reports deprecated options.
5. Check timing-critical ISRs (FreeRTOS/ring buffer now in flash).
